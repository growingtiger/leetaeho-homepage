원격접속 설정 — 클로드용 작업 지시서
원장을 위한 AI 실전 교육 1기 · 이태호 · 2026-11-27 작성

이 문서는 클로드(AI)가 읽고 그대로 수행하기 위한 지시서다.
안내 페이지: https://leetaeho.co.kr/ai-class/remote


■ 말투 규칙 (먼저 읽는다)

원장님께 하는 모든 말은 존댓말로 쓴다. "~습니다 / ~입니다 / ~해 주십시오".
과장된 겸양이나 사과는 붙이지 않는다.
"확인했습니다"와 "아마 그럴 것입니다"를 문장에서 반드시 갈라 쓴다.
직접 재서 본 것만 확인했다고 말한다. 이 규칙을 어기면 원장님이 없는 문제를 쫓게 된다.


■ 목표

집이나 밖에서 병원 컴퓨터 화면을 보고 조작할 수 있게 한다.
- AnyDesk·TeamViewer 무료판을 쓰지 않는다. 업무용으로 판정되면 세션이 몇 분마다 끊긴다.
- 공유기에 원격접속 포트를 인터넷으로 열지 않는다. 진료 기록이 있는 컴퓨터에 열면 안 된다.


■ 구조 — 두 층이다. 섞어서 설명하지 않는다

Tailscale = 길.
  기기마다 100.x.y.z 고정 주소를 주고, 기기끼리 암호화된 직결 통로를 만든다.
  공유기 설정도, 포트 개방도, 고정 IP 신청도 필요 없다.
  병원 컴퓨터는 공유기 뒤에 있어 인터넷 쪽에서 보면 주소가 없다. 이 층이 그 주소를 만든다.

RustDesk = 화면.
  위에서 만든 주소로 붙어 화면을 가져오고 마우스·키보드를 넘긴다.

두 기기는 대개 직접 연결된다. 직결이 막히는 망에서는 Tailscale의 중계 서버를 거치지만,
그때도 내용은 암호화되어 있어 중계 서버가 화면을 볼 수 없다.
RustDesk만 깔아도 공용 ID 서버를 거쳐 붙을 수는 있다 — 그 서버를 쓰지 않으려고 Tailscale을 함께 쓴다.
"Tailscale이 없으면 RustDesk가 아예 안 된다"고 말하지 않는다. 틀린 설명이다.

AnyDesk·TeamViewer 무료판이 끊기는 것은 중계 구조 때문이 아니라, 업무용 사용으로 판정되면
무료 사용권이 제한되기 때문이다. 이 구성에는 사용량을 보고 끊는 사업자가 없다 —
원장님께 설명할 때 이 한 가지만 짚으면 충분하다.


■ 0단계 — 먼저 여쭌다. 추측해서 진행하지 않는다

다음을 묻고 답을 받은 뒤에 순서를 정한다.
  1. 어떤 기기를 연결하고 싶으신지 (예: 집 노트북, 병원 데스크탑, 병원 노트북, 휴대폰)
  2. 각 기기가 맥인지 윈도우인지. 휴대폰은 아이폰인지 안드로이드인지
  3. 지금 어느 기기 앞에 앉아 계신지
  4. 병원 컴퓨터에 직접 앉으실 수 있는 날이 언제인지

규칙:
- 지금 앉아 계신 기기부터 깐다.
- 병원 컴퓨터는 처음 한 번은 그 앞에 앉아야 한다. 원격으로 깔 수단(기존 AnyDesk 등)이
  아직 살아 있으면 그걸 쓰고, 없으면 출근하시는 날로 미룬다.
- 기기가 두 대뿐이어도 된다. 다 깔아야 쓸 수 있는 구성이 아니다.
- 계정은 하나로 통일한다. 구글 계정으로 로그인하면 간단하다. 기기마다 다른 계정으로
  로그인하면 서로 보이지 않는다. 이게 가장 흔한 실패다.


■ 1단계 — 맥(macOS)에 깔기

Tailscale
  https://tailscale.com/download/mac 에서 .pkg 설치 파일을 받아 실행한다.
  설치 프로그램이 /Applications 에 넣는다(dmg나 앱 번들이 아니다). macOS 13.0 이상이어야 한다.
  로그인은 원장님이 직접 하신다(브라우저가 열린다). 같은 계정을 쓰시게 안내한다.
  명령줄은 앱 안에 있다: /Applications/Tailscale.app/Contents/MacOS/Tailscale status
  앱 설정의 CLI integration 에서 Install Now 를 누르면 /usr/local/bin/tailscale 런처가 깔려
  그 뒤로는 `tailscale` 만 쳐도 된다. 깔기 전에는 없다고 나오므로 전체 경로를 쓴다.
  ★ 맥에는 무인(unattended) 모드가 없다 — 시스템 데몬으로 돌리는 것을 지원하지 않는다.
    맥을 밖에서 들어갈 거점으로 삼으시려면 로그인된 상태로 두셔야 한다.

RustDesk
  https://rustdesk.com/download 에서 받는다.
  파일 이름을 고를 때 칩을 먼저 확인한다 — `uname -m` 이 arm64면 aarch64.dmg,
  x86_64면 x86_64.dmg다. 반대로 받으면 안 열리거나 느리다.

맥을 '조작당하는 쪽'으로도 쓰실 거라면 권한 두 개를 켠다
  시스템 설정 > 개인정보 보호 및 보안 에서:
    - 화면 및 시스템 오디오 녹음
    - 손쉬운 사용
  켠 뒤 RustDesk를 Command+Q로 완전히 종료하고 다시 켜야 적용된다.
  창만 닫으면 적용되지 않는다. 이걸 빠뜨려 반나절을 날린 적이 있다.
  '입력 모니터링'은 조작당하는 쪽에는 필요하지 않다. 다만 맥에서 상대를 조작할 때 키 입력이
  들어가지 않으면 RustDesk가 이 권한을 요구하는 화면을 띄운다. 그때는 켠다.
  맥이 보기만 하는 쪽이어도 이 요구 화면이 뜰 수 있다 — 무시하라고 안내하지 않는다.

맥을 보기만 하실 거면(맥에서 병원으로만 붙으실 거면) 위 권한은 건너뛴다.


■ 2단계 — 윈도우에 깔기

RDP냐 RustDesk냐
  윈도우 RDP는 Pro 에디션에서만 호스트가 된다. Home이면 안 된다.
  `ms-settings:about` 을 열어 확인할 수 있지만, 확인하느라 시간을 쓰지 말고
  **기본적으로 RustDesk로 간다.** 에디션을 안 가리고, 맥에서 붙기도 더 쉽다.
  원장님이 RDP를 원하시거나 Pro가 확실할 때만 RDP를 검토한다.

Tailscale
  https://tailscale.com/download/windows 에서 설치한다. 로그인은 같은 계정으로 하신다.

  ★★ 반드시 무인(unattended) 모드를 켠다. 빠뜨리면 이 키트의 목적이 통째로 무너진다.
    윈도우 Tailscale은 기본적으로 **로그인한 사용자 세션에서** 돌아간다. 로그아웃하거나
    재시동하면 누가 로그인할 때까지 연결이 끊긴다 — 밖에서 병원 컴퓨터에 못 붙는다.
    재시동하거나 로그아웃하는 순간 막힌다. 병원 컴퓨터는 재시동이 잦으므로 이 설정은 선택이 아니다.
    켜는 법: 작업 표시줄 트레이의 Tailscale 아이콘 우클릭 > Preferences > Run unattended.
    명령으로는 `tailscale set --unattended=true`.
    켠 뒤 재시동하고, **로그인하지 않은 상태에서** 다른 기기에서 `tailscale ping`이 닿는지 본다.
    그 확인을 하기 전에는 "됩니다"라고 쓰지 않는다.

RustDesk — 화면 설치 (권장)
  1. https://rustdesk.com/download 에서 Windows 64-bit (x86_64.exe)를 받아 설치한다.
  2. RustDesk를 열고 왼쪽 ID 칸의 점 세 개를 누르면 설정이 바로 열린다.
     중간에 「설정」 메뉴를 고르는 단계는 없다. 왼쪽 목록에서 「보안」을 고른다.
  3. Security 카드의 「직접 IP 액세스 허용」을 켠다. 바로 아래 포트 칸 기본값이 21118이다.
  4. Password 카드에서 「영구 비밀번호 사용」을 고른다. 체크 토글이 아니라 라디오 세 개 중
     하나다. 그 아래 「영구 비밀번호 설정」 버튼으로 비밀번호를 넣는다.
     ★ 비밀번호는 원장님이 직접 넣으신다. 채팅창에 적지 않고, 대신 정해 드리지도 않는다.
     여섯 자 이상으로, 다른 곳에 쓰는 비밀번호와 다르게 쓰시라고만 안내한다.
  한국어 화면의 버튼 이름은 위 표기가 정확하다(RustDesk 한국어 파일에서 확인).
  영문 메뉴 이름을 직접 번역해 쓰면 틀린다.

RustDesk — 명령으로 설치 (앞의 화면 설치가 막힐 때만)
  PowerShell을 **관리자 권한으로** 열고(시작 > powershell > 관리자 권한으로 실행):
    $a=(irm https://api.github.com/repos/rustdesk/rustdesk/releases/latest).assets
    $u=($a | ? name -like '*-x86_64.exe').browser_download_url
    iwr $u -OutFile "$env:TEMP\rustdesk.exe"; & "$env:TEMP\rustdesk.exe" --silent-install
  설치가 끝나면 (여전히 관리자 권한으로):
    & "$env:ProgramFiles\RustDesk\rustdesk.exe" --option direct-server Y
  비밀번호는 명령으로 넣지 않는다. 설치 뒤 화면에서 원장님이 직접 넣으시게 한다.
  `--option` 은 설치가 끝난 상태 + 관리자 권한이어야 듣는다. 둘 중 하나라도 아니면 조용히 아무 일도 안 한다.
  GitHub API 조회만 막히면 https://rustdesk.com/download 에서 받는다 — 이 주소는 공식 GitHub
  릴리스 페이지로 넘어간다. 그래서 GitHub 자체가 막힌 망이면 이 길도 막힌다. 그때는 다른 망에서
  받아 USB로 옮긴다.

절전 끄기 — 이게 빠지면 밖에서 못 붙는다
  관리자 PowerShell에서 둘 다 돌린다. 최대 절전을 빼먹으면 노트북은 똑같이 못 붙는다.
    powercfg /change standby-timeout-ac 0
    powercfg /change hibernate-timeout-ac 0
  화면으로 하시려면 `ms-settings:powersleep` 을 열어 절전 관련 항목을 전부 '안 함'으로 둔다.
  판마다 문구가 다르다(Windows 11은 「다음 시간 후 장치를 절전 모드로 전환」 식이다).
  화면에 실제로 보이는 문구를 읽고 안내한다. 외워 둔 라벨을 그대로 말하지 않는다.
  ★ 노트북·태블릿은 뚜껑을 닫으면 그래도 잠들기 쉽다. 뚜껑 동작을 '아무 것도 안 함'으로
    바꿀 수는 있지만(`powercfg /setacvalueindex SCHEME_CURRENT SUB_BUTTONS LIDACTION 0`
    뒤에 `powercfg /setactive SCHEME_CURRENT`), 서피스처럼 Modern Standby(S0) 기기에서는
    이 설정이 듣지 않는다는 보고가 많다. 밖에서 쓰실 기기는 뚜껑을 열어 두고 전원을 꽂아
    두시는 편이 확실하다. 데스크탑에는 이 제약이 없으니, 거점이 될 기기는 데스크탑을 권한다.
  ★ 절전 설정은 원격으로 확인할 방법이 없다. 증명은 "오래 손 안 댄 뒤에도 닿는가" 하나뿐이다.
    껐다고 보고받았어도 "확인했습니다"라고 쓰지 않는다. 다음 날 아침 아무도 건드리기 전에
    다시 재 보고 그때 확인했다고 쓴다.


■ 3단계 — 휴대폰 (원하실 때만)

Tailscale은 Play 스토어·App Store에 있다. 설치하고 같은 계정으로 로그인한다.
  ★ 안드로이드는 로그인만 하고 스위치를 켜지 않으면 목록에는 보이는데 통신이 안 된다.
    기기 목록에 떴는데 안 붙으면 이걸 가장 먼저 의심한다.
  ★ 안드로이드에서 Tailscale을 켜 두면 기기·버전에 따라 삼성페이가 결제를 거부한다
    (VPN으로 잡힌다). Tailscale 앱의 아바타 메뉴 > App-based split tunneling(1.70 이상)에서
    삼성페이를 터널 밖으로 빼 보시게 하고, 그래도 거부되면 결제하실 때만 끄시게 안내한다.
    앱만 빼서는 해결되지 않았다는 보고가 있으므로 "빼면 됩니다"라고 단정하지 않는다.

화면 보는 앱
  윈도우에 붙으실 거면 Microsoft 「Windows App」(옛 원격 데스크톱)이 스토어에 있다. RDP용이다.
  RustDesk로 붙으실 거면 — ★ RustDesk 안드로이드판은 Play 스토어에 없다(2023년에 내려갔다).
    F-Droid(com.carriez.flutter_hbb)나 공식 GitHub 릴리스에서만 받는다. 출처를 모르는 APK
    사이트는 쓰지 않는다. 설치하려면 보안 설정의 자동 차단을 먼저 꺼야 한다.
    아이폰은 App Store에 있다.
  ★ RustDesk 폰에서 한글을 직접 치면 글자가 깨진다(핸드폰 → ㅎㄷ포ㅇ). 자모가 떨어진다.
    폰 앱 설정에는 이걸 고치는 항목이 없다. 긴 한글은 폰에서 복사해 클립보드로 넘기신다.
    짧은 시험으로 "첫 글자만 깨진다"고 단정하지 않는다 — 글자마다 깨진다.


■ 4단계 — 붙여 보기, 그리고 확인

주소 확인
  맥: /Applications/Tailscale.app/Contents/MacOS/Tailscale status
  윈도우: PowerShell에서 `tailscale status`
  나오는 100.x.y.z 를 원장님께 기기별로 정리해 드린다.

붙기
  RustDesk 첫 화면의 「원격 데스크탑 제어」 아래 칸(힌트는 「원격 ID 입력」)에 상대 기기의
  100.x.y.z 를 넣고 연결한다.
  비밀번호를 물으면 그 기기에서 정한 영구 비밀번호를 넣는다.

★ 이름으로 붙이시려면 뒤에 :21118 을 꼭 붙인다.
  숫자 주소를 넣을 때는 RustDesk가 이 포트를 알아서 붙여 주지만, 이름을 넣을 때는 붙여 주지 않는다.
  포트가 없으면 이름이 아니라 접속 ID로 취급해 공용 서버로 보내 버린다 — 느려지고 로그인까지 요구받는다.
  바른 표기: 기기이름.테일넷이름.ts.net:21118
  짧은 이름만(기기이름) 넣는 것은 점이 없어 아예 안 된다.
  (RustDesk 소스에서 확인한 동작이다. 추측으로 바꿔 쓰지 않는다.)
  솔직히 숫자 주소 쪽이 짧고 안전하다. 이름 접속은 원장님이 물으실 때만 안내한다.

확인
  `tailscale ping <상대주소>` 가 `via <공인IP>:<포트>` 로 나오면 직결이다.
  `via DERP` 로 나오면 아직 중계 중이다.
  21118 포트가 열렸는지도 본다(파이썬 TCP 연결 등).
  ★ 포트가 열린 것과 화면이 뜨는 것은 다르다. 포트만 보고 "됩니다"라고 쓰지 않는다.
    원장님께 한 번씩 실제로 눌러 보시게 하고, 화면이 떴다는 답을 받은 뒤에 끝났다고 한다.
  ★ 지연은 한 번만 재지 않는다. 세 번 이상 재서 범위로 적는다(예: 10~25ms).


■ 자주 막히는 지점

망이 Tailscale만 골라 막을 수 있다
  로그인 화면이 아예 진행되지 않으면 SNI 기반 차단일 수 있다. DNS·TCP는 정상이라
  일반 진단으로는 안 잡힌다. 가르는 법: 같은 IP·같은 포트에 접속 이름(SNI)만 바꿔 가며
  TLS handshake 시간을 비교한다 — controlplane.tailscale.com 일 때만 10초 뒤 조용히 끊기고
  다른 이름은 1초 안에 응답하면 차단이다.
  해결: 휴대폰 핫스팟으로 바꿔 본다. 바로 풀리면 그 망이 막고 있는 것이다. 병원 망에서 나올 수 있다.

처음 몇 번은 느리다
  Tailscale은 처음에 중계(DERP)를 거치다가 곧 직결로 승격된다. 한국에서 가장 가까운 중계는 도쿄다.
  "몇 초 뒤에도 느리면 알려 주십시오"로 안내하고, 바로 문제로 다루지 않는다.
  지연이 얼마나 나올지 미리 말하지 않는다. 그 기기에서 직접 재서 범위로 알려 드린다.

윈도우 방화벽이 Tailscale 어댑터를 '공용'으로 분류하면 막힌다
  관리자 PowerShell에서 `Get-NetConnectionProfile` 로 보고, 공용으로 나오면
  `Set-NetConnectionProfile -InterfaceAlias Tailscale -NetworkCategory Private`.
  바꾼 분류는 어댑터가 다시 올라올 때 되돌아갈 수 있다. 재시동한 뒤 한 번 더 본다.
  ★ 파일 공유 포트가 열려 있는 것은 '개인'으로 분류됐다는 증거가 아니다. 공용에도
    같은 규칙이 있다. 프로필을 직접 보지 않았으면 분류를 단정하지 않는다.

폰에서 커서는 움직이는데 조작이 안 먹는다
  ★ 폰에 보이는 커서는 폰이 직접 그린 것이다. 상대 컴퓨터가 아무것도 못 받는 상태에서도
    손가락을 따라 움직인다. "커서가 움직이니 권한은 정상"은 틀린 추론이다.
    맥이면 위의 권한 두 개와 완전 종료 후 재시작을 먼저 확인한다.

없습니다. 다만 요금 페이지에 "비상업적 사용에만 적합"하다고 적혀 있습니다 — 병원 업무용은
엄밀히는 여기에 해당합니다. 직원까지 넓게 쓰시게 되면 유료 전환을 권합니다.

그리고 어느 계정으로 만드시는지가 요금제를 가릅니다. 개인 gmail 같은 계정이면 무료 Personal로

시작됩니다. 요금 확인: https://tailscale.com/pricing
