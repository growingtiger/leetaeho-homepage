왜 다섯 곳에 가입하나요

원장님이 말로 설명한 프로그램이 휴대폰에서 열리기까지 다섯 곳이 한 가지씩 맡습니다. 모두 원장님 이름의 계정이라, 교육이 끝난 뒤에도 만든 것이 그대로 원장님 것으로 남습니다.

  1. Claude원장님 설명을 듣고 프로그램을 만드는 AI
  2. Claude 앱노트북 안에서 Claude가 직접 파일을 만들고 고치는 작업실
  3. GitHub만든 프로그램을 보관하고, 고칠 때마다 이전 판을 남겨 두는 창고
  4. Vercel보관된 프로그램에 인터넷 주소를 붙여 휴대폰에서 열리게 하는 곳
  5. Supabase여러 기기와 직원이 같은 기록을 함께 보고 쓰는 저장소

  1. 01

    Claude 유료 구독

    유료 · 교육비 별도

    왜 필요한가요: 프로그램을 실제로 만들어 주는 AI입니다. 교육에서 쓰는 Claude Code는 무료 요금제에서는 열리지 않아 유료 구독이 있어야 합니다.

    • claude.ai 에서 Google 계정이나 이메일로 가입하고 로그인합니다.
    • claude.com/pricing 에서 Pro 또는 Max 칸의 Claude 사용해 보기를 눌러 결제합니다. Pro 칸에 Claude Code가 들어 있는 것을 확인하실 수 있습니다.

    Pro로도 실습할 수 있지만, 하루 종일 쓰면 사용 한도에 걸려 잠시 기다려야 할 수 있습니다.

  2. 02

    Claude 데스크톱 앱 설치

    무료

    왜 필요한가요: 데스크톱 앱의 Code 탭에서는 Claude가 원장님 노트북 안에서 파일을 직접 만들고 고치고, GitHub에 올리는 일까지 합니다. 교육 내내 이 앱으로 작업합니다.

    • claude.com/download 의 데스크톱 칸에서 맥은 macOS 줄, 윈도우는 Windows 줄의 다운로드를 누릅니다. ARM 칩 윈도우 노트북(일부 Surface 등)은 Windows(arm 64) 줄을 씁니다.
    • 내려받은 파일로 설치하고, 1단계 계정으로 로그인합니다. 맥은 Claude 아이콘을 응용 프로그램 폴더로 끌어다 놓으시면 됩니다.

    윈도우 노트북만

    • git-scm.com/install/windows 에서 Click here to download를 눌러 Git을 내려받습니다.
    • 설치 화면은 전부 기본값 그대로 Next를 누르고, 끝나면 Claude 앱을 완전히 껐다가 다시 켭니다.
  3. 03

    GitHub 계정

    무료

    왜 필요한가요: 만든 프로그램을 인터넷에 보관해 두는 창고입니다. 고칠 때마다 이전 판이 남아 잘못 고쳐도 되돌릴 수 있고, 노트북이 바뀌어도 그대로 이어서 작업할 수 있습니다. 다음 단계의 Vercel과 Supabase도 이 계정으로 가입합니다.

    • github.com/signup 에서 화면 안내대로 이메일, 비밀번호, 영문 사용자 이름을 넣습니다.
    • 안내에 따라 이메일 인증을 마칩니다.
  4. 04

    Vercel 계정

    무료

    왜 필요한가요: 만든 프로그램에 인터넷 주소를 붙여, 원장님과 직원들 휴대폰에서 앱처럼 열리게 해 줍니다. GitHub에 고친 내용을 올리면 자동으로 반영됩니다.

    • vercel.com/signup 에서 Continue with GitHub를 눌러 3단계 계정으로 연결합니다.
    • 요금제를 묻는 화면이 나오면 Hobby를 고릅니다.

    실습은 무료 요금제로 합니다. 만든 앱을 병원 업무에 계속 쓰시려면 그때 Pro(1인 월 20달러)로 바꾸셔야 합니다. Vercel 약관상 무료 요금제는 비상업적 개인 사용만 허용합니다.

  5. 05

    Supabase 계정

    무료

    왜 필요한가요: 마취 기록지나 근무표처럼 여러 사람이 함께 쓰는 프로그램은 기록을 한곳에 모아 둬야 합니다. 수술방 태블릿에서 적은 내용을 원장실 PC에서 바로 볼 수 있게 해 주는 저장소입니다.

    • supabase.com/dashboard/sign-up 에서 Continue with GitHub를 눌러 3단계 계정으로 연결합니다.
    • 조직(Organization)을 만들라는 화면이 나오면 병원 이름을 넣고 무료(Free) 플랜을 고릅니다. 나머지 칸은 기본값 그대로 두셔도 됩니다.
    • 프로젝트는 교육 당일 함께 만듭니다. 미리 만들지 않으셔도 됩니다.

어느 단계든 막히시면 그 화면을 찍어 단톡방에 올려 주십시오. 교육 전에 풀어 드리겠습니다. 코딩을 모르셔도 됩니다. 저도 코드를 직접 쓰지 않고 병원 프로그램을 만들고 있습니다.
