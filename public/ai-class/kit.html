스타터 키트 설치

이 키트를 깔고 나면, 만들고 싶은 프로그램을 Claude에게 말로 주문하는 것만으로 저장·배포·휴대폰 앱까지 끝납니다. 제가 병원 프로그램을 만드는 방식을 그대로 옮겨 담았습니다.

Claude말을 듣고 코드를 씁니다
GitHub코드를 비공개로 보관합니다
Vercel주소를 받고 서버를 돌립니다
Supabase병원 데이터를 보관합니다
  1. 01

    내 키트 받기

    1분

    교육 당일 받으신 개인 코드를 넣어 주십시오. 키트는 원장님마다 따로 만들어 이름이 들어 있습니다.

    Claude 데스크톱 앱에서 Code 탭을 열고 새 대화에 아래 문장을 그대로 붙여 넣습니다. 내려받기·설치 허락을 물으면 허락해 주십시오.

    Claude가 규칙집과 조립법을 깔고, 필요한 도구(Node, GitHub CLI, Vercel CLI)를 내려받습니다. 관리자 비밀번호는 필요 없습니다.

  2. 02

    GitHub 로그인 승인

    1분

    Claude가 XXXX-XXXX 모양의 코드를 알려 드립니다.

    • github.com/login/device 를 엽니다.
    • 'Signed in as (내 아이디)' 옆 Continue를 누릅니다.
    • 코드를 넣고 Continue → Authorize github를 누릅니다.
    • "Congratulations, you're all set!"이 보이면 끝입니다.
  3. 03

    Vercel 로그인 승인

    1분

    Claude가 https://vercel.com/oauth/device?user_code=… 주소를 알려 드립니다.

    • 그 주소를 엽니다(Vercel에 로그인돼 있어야 합니다).
    • 화면의 코드가 Claude가 알려 준 코드와 같은지 보고 Allow Access를 누릅니다. Continue가 먼저 보이면 Continue를 누른 뒤 Allow Access를 누릅니다.
    • Claude 화면에 "Vercel 로그인: (내 아이디)"가 나오면 끝입니다.
  4. 04

    Supabase 프로젝트 하나 만들기

    3분

    앞으로 만드는 모든 앱이 이 프로젝트 하나를 같이 씁니다. 앱마다 새로 만들지 않습니다.

    • supabase.com/dashboard/new 를 엽니다. 처음 가입하신 분은 Create a new organization 화면이 나옵니다. Name에 병원 이름을 넣고, Type은 Company, Plan은 Free 그대로 두고 Create organization을 누릅니다.
    • 이미 Supabase를 쓰고 계신 분은 위 주소 대신 조직 목록에서 조직을 열고 New project를 누릅니다.
    • Project name에 미리 적힌 글자를 지우고 clinic-apps를 넣습니다.
    • Database password는 Generate a password를 누르고 따로 적어 둡니다.
    • Region 칸 아래 Need a specific region?을 누르고 Northeast Asia (Seoul)를 고릅니다. 나중에 바꿀 수 없습니다. 링크나 서울이 보이지 않으면 Asia-Pacific을 고르셔도 됩니다.
    • Create new project를 누르고 1~2분 기다립니다.
  5. 05

    열쇠 붙여 넣기

    2분

    Claude가 메모장(맥은 텍스트 편집기)으로 keys.env 파일을 열어 드립니다. 열쇠는 이 파일에만 둡니다. 채팅창에는 절대 붙여 넣지 마십시오.

    • 방금 만든 프로젝트 화면 주소창에서 supabase.com/dashboard/project/ 뒤의 영문 글자를 복사해 SUPABASE_URL= 뒤에 붙여 넣습니다.
    • API Keys 화면을 열고 프로젝트를 고른 뒤, Secret keys 칸의 키를 복사해 SUPABASE_SECRET_KEY= 뒤에 붙여 넣습니다. sb_secret_로 시작하는 키입니다.
    • 저장(맥 Command+S, 윈도우 Ctrl+S)하고 Claude에게 "저장했어"라고 말합니다.
    • Claude가 "모두 준비됐습니다"라고 하면 설치가 끝난 것입니다.
  6. 06

    첫 앱 주문하기

    10분

    처음에는 작게 주문하고, 써 보면서 "여기 고쳐 줘"로 키웁니다. 예를 들면 이렇게 말합니다.

    진료실 소모품 재고 체크 앱 만들어 줘. 직원 셋이 휴대폰으로 같이 써. 품목, 현재 수량, 최소 수량을 적고, 최소 수량보다 적으면 맨 위에 빨간 글씨로 보여 줘.

    몇 분 뒤 Claude가 주소와 비밀번호를 알려 드립니다. 휴대폰에서 주소를 열고 비밀번호를 넣은 뒤 홈 화면에 추가하면 앱이 됩니다.

    • 아이폰: Safari 주소창 옆 …(또는 공유 버튼) → 공유 → 홈 화면에 추가 → '웹 앱으로 열기' 켜고 추가
    • 안드로이드: Chrome 오른쪽 위 점 세 개 → 설치 및 바로가기 만들기(또는 홈 화면에 추가) → 설치

알아 두실 것

Vercel 무료(Hobby) 요금제는 약관상 비상업적 개인 용도만 허용합니다. 병원 업무에 쓰는 앱은 Pro 요금제가 필요합니다(vercel.com/pricing).

Supabase 무료 프로젝트는 1주일 동안 쓰지 않으면 잠시 멈춥니다. 앱에 "저장 오류"가 뜨면 조직 목록에서 조직과 프로젝트를 차례로 열고 Resume project를 누르면 됩니다.

시험할 때는 가짜 환자 이름을 쓰십시오. 고칠 때는 "무엇을 눌렀고, 무엇이 보였고, 무엇을 기대했는지"를 말하거나 화면 캡처를 붙이면 빠릅니다.
